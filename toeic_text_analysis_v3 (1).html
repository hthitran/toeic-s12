💬 Functional Phrases

Common phrases used in each text type — useful for recognition & TOEIC Speaking tasks.

📢 Announcements Thông báo
🔔 Opening / Getting Attention
  • Attention, please. / Could I have your attention, please?
  • Ladies and gentlemen, ...
  • This is an important announcement for all ...
  • We would like to inform you that ...
📌 Stating the Purpose
  • Due to [reason], ... will be [closed / cancelled / postponed].
  • We are pleased to announce that ...
  • Please be advised that ...
  • Effective [date/time], ...
✅ Closing / Instructions
  • We apologize for any inconvenience caused.
  • For more information, please contact ...
  • Thank you for your cooperation / patience.
  • Please direct all questions to ...
📣 Advertisements Quảng cáo
🎯 Hook / Opening
  • Are you looking for ...? / Have you ever ...?
  • Introducing [product/service] — the answer to ...
  • Do you want to [benefit]?
  • Say hello to your new [product]!
💡 Highlighting Features
  • We offer / feature / provide ...
  • For a limited time only, ...
  • [Product] is now available at / for ...
  • Get [X]% off on all [items] this [period].
📞 Call to Action
  • Visit us at / Call us at / Go to our website at ...
  • Don't miss this opportunity!
  • Come in today and see for yourself.
  • Register / Sign up / Order now!
🎤 Introductions Giới thiệu
👋 Welcoming the Audience
  • Welcome, everyone, to ...
  • Good [morning/afternoon/evening], ladies and gentlemen.
  • Thank you for joining us today at ...
  • It's a pleasure to have you here.
🎙 Introducing a Speaker / Guest
  • It is my great pleasure / honor to introduce ...
  • Please join me in welcoming ...
  • [Name] is an expert in / the founder of / known for ...
  • Tonight's / Today's guest is ...
📋 Introducing a Program / Event
  • Today, we'll be [discussing / exploring / covering] ...
  • Before we begin, I'd like to go over ...
  • Let me walk you through today's agenda.
  • Without further ado, let's get started!
📰 News Reports Tin tức
📡 Opening the Broadcast
  • Good [morning/evening]. This is [name] with [station].
  • In today's / tonight's top stories, ...
  • Here is your [weather / traffic / news] update.
  • We begin with breaking news from ...
📋 Reporting Events
  • According to [source], ...
  • [Event] took place / occurred / is expected to ...
  • Officials / Authorities have announced that ...
  • A [report / study / survey] shows / reveals that ...
🔄 Handing Over / Closing
  • We'll have more on this story as it develops.
  • Stay tuned for more details.
  • For more information, visit [website].
  • That's all for now from [name], [station].
📞 Phone Messages Tin nhắn thoại
📲 Answering / Greeting
  • Thank you for calling [business name].
  • You have reached [name / department].
  • Hello, and welcome to [company].
  • Hi, this is [name] calling from / about ...
📋 Providing Options
  • For [service], press [number].
  • To speak with a representative, please hold.
  • Our office hours are [days] from [time] to [time].
  • If this is an emergency, please hang up and call ...
✉ Leaving / Requesting a Message
  • Please leave a message after the tone / beep.
  • Please include your name, number, and reason for calling.
  • We will return your call within [time].
  • Please call back during business hours.
